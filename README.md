# CopyCenter — информационная система копицентра

Курсовой проект по теме **«Разработка информационной системы учёта заказов и расчёта стоимости услуг копицентра»**.

Приложение предназначено для автоматизации работы копицентра: ведения клиентской базы, оформления заказов, расчёта стоимости услуг и учёта платежей.

## Используемые технологии

- **C#** — язык программирования.
- **WPF** — разработка графического интерфейса.
- **PostgreSQL** — хранение данных.
- **XAML** — описание интерфейса приложения.

## Функциональные возможности

- Авторизация пользователей с разграничением прав доступа.
- Управление клиентами и их контактными данными.
- Добавление и редактирование услуг и тарифов.
- Создание, просмотр и изменение заказов.
- Автоматический расчёт стоимости заказа.
- Учёт платежей и отслеживание состояния заказов.

## Роли пользователей

**Администратор** — управление пользователями, услугами, тарифами и данными системы.

**Оператор** — работа с клиентами, оформление заказов, расчёт стоимости услуг и регистрация платежей.

## База данных

Для хранения информации используется PostgreSQL. База данных содержит сведения о пользователях, клиентах, услугах, тарифах, заказах и платежах.

## Назначение проекта

Разработанная система позволяет сократить время оформления заказов, упростить расчёт стоимости услуг и обеспечить централизованное хранение информации о деятельности копицентра.
